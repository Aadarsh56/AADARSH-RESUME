# 📄 Aadarsh Vidyarthi — Portfolio Resume Website

A clean, responsive **personal portfolio and resume website** built with HTML & CSS, featuring dark/light mode toggle and modern design aesthetics.

## 🌐 Live Preview

> Open `INDEX.html` directly in a browser or host on GitHub Pages.

## ✨ Features

- 🌙 **Dark / Light Mode** toggle with localStorage persistence
- 📋 Skills section with badge-style tags
- 💼 Project highlights and experience section
- 🛠️ Freelancer & Consultant services section
- 📱 Responsive layout with modern Inter font

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Page structure & semantics |
| CSS3 | Styling, animations, dark mode |
| JavaScript | Theme toggle logic |
| Google Fonts (Inter) | Typography |

## 📁 Project Structure

```
AADARSH RESUME/
├── INDEX.html      # Main portfolio page
├── STYLE.css       # All styles including dark mode
└── profile.jpg     # Profile photo
```

